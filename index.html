About PixelLite

PixelLite is a browser-based image compression tool designed to help people make image files smaller for online forms, applications, documents and everyday sharing.

The tool lets you select a JPG, PNG or WebP image, choose a maximum target size, adjust the quality setting and download a compressed JPEG result. The current tool performs image processing in your browser using the device's built-in web capabilities.

PixelLite is an independent project and is not affiliated with, endorsed by, or sponsored by Google. We aim to make the tool straightforward and explain its limitations clearly.

How It Works

  1. Choose an image in JPG, PNG or WebP format, or drag it into the upload area.
  2. Select a maximum target size from 1 MB to 3 MB.
  3. Adjust the quality slider if needed, then select “Compress image”.
  4. Compare the original and compressed previews and check the resulting file size.
  5. Select “Download compressed image” to save the JPEG file to your device.

Image processing is performed locally in the browser in this version. The output is converted to JPEG; transparent areas are filled with white. The tool may reduce image dimensions and quality to try to meet the chosen maximum size. A target size is not guaranteed for every image, so always inspect the result for clarity and readability.
